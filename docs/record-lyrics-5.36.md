# v5.36.0 唱片页歌词与交互

继续 v5.35.0 已交付的唱片页，不重新初始化项目。长按歌词按钮或通过更多菜单打开唱片页歌词设置，直接选择已有的 14 种原生样式、高亮配色、字号、行距、动效强度、译文、对齐及减少动态效果。与完整歌词页共用已保存的外观设置；初次未配置时保持经典滚动、白色居中和紧凑行距。原来的自定义照片与封面背景独立保留。

滑动浏览歌词时显示带时间的播放这句和回到当前按钮。浏览和返回不改变音频进度，确认跳转使用真实服务时钟并计入每曲歌词偏移。同步校准可直接在唱片页调整，按曲目保存，与完整歌词页互通，切到另一首歌时关闭旧校准窗口。

歌词时间线、字号、布局或歌曲会话变化时取消旧手势，防止旧触点跳转新曲或同地址的新会话。失去前台焦点或页面停止时关闭唱片与歌词的连续重绘，恢复焦点后重新跟随系统及应用减少动态效果设置。暂停和背景参数不变时避免不必要的重复背景与唱片刷新。歌词边缘淡出不改变时间线。

新增 Android 原生检查使用真实播放服务、设置控件、长按入口、完整歌词页、每曲校准、手势和实际音频时钟。继续完整回归、64 来源匿名只读检测、原签名和从 v5.6.0 / v5.35.0 覆盖升级验证。最终证据以后续验证记录为准。此轮不宣称第三方来源、会员账号、服务器或协议限制均已解决。
