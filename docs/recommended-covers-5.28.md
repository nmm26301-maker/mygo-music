# 5.28 推荐歌曲封面修复

原因：音乐源推荐、搜索、歌单等页面的歌曲行共用 SourceBrowser.tracks，旧实现只创建文字按钮，没有创建封面视图，因而即便歌曲或专辑提供 imageUrl 也不会显示。原有 artwork() 已支持歌曲 imageUrl 与 album.imageUrl，图像下载也有来源请求头、缓存、尺寸和大小限制及异步目标标记；本次复用这些流程，不另建封面搜索服务。

## 修复

- 每个歌曲/单集行左侧增加 40dp 圆角封面，使用已有来源图像加载器获取实际图片；列表行原有点击播放、长按操作和队列规则保留，点击封面区域同样播放该歌曲。
- 没有封面、正在加载或加载失败时显示本地渐变音乐图块；不会把占位图伪装成专辑封面。其他来源卡片缺图时也使用同一占位样式。
- 歌曲标题、歌手、不可用状态和已有封面地址规则不改变。图片成功加载后替换占位，沿用来源请求头和缓存隔离。

## 验证状态

新增真实插件首页推荐测试：专辑内嵌 imageUrl 加载成原生位图，检查实际像素而非只检查网址；缺图与无效图响应保留本地占位；封面与文字不重叠；封面区域点击后原生播放器播放对应来源歌曲，队列和来源音频请求头正确。完整 Android 回归、原签名与从 5.27.0 覆盖安装待云端完成后记录。
