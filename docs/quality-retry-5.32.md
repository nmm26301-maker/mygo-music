# v5.32.0 音质重试与来源说明

音质失败弹窗及其登录回调原先只比较歌曲地址，同一歌曲的新会话、后续成功的切换或新的待准备音质都可能受到旧操作影响。本版把重试交给播放服务，检查服务实例、播放代次、失败编号、当前歌曲和是否仍有新的替换进行。仅当前有效的失败可以重试；原音频与用户最近的暂停、位置、音量和播放队列继续由原服务保留。

打开中的音质面板随播放状态刷新准备提示、来源说明和当前选择，无需关闭重开。

来源报告的无损标签与已报告编码分开解释：明确 AAC、MP3、Opus、Vorbis 等有损编码与无损标签同时出现时显示不一致；FLAC、ALAC 显示无损编码；仅有 M4A、OGG、HLS 等容器或传输描述时保持未核验。该说明仍基于来源报告，不等同于对原始母带、输出链路或音频真伪的测量。请求档位、来源原始元数据和缓存来源信息保留，不因为兼容转换生成 FLAC 而把原 AAC 改成无损来源。

新增受控测试故意让插件为真实 AAC 文件返回无损标签，通过原生播放、音质弹窗与停止服务器后的离线回放验证说明；还覆盖原音频保护、暂停位置、原队列、同曲新会话、迟到登录、新的待准备音质与停止后的旧回调。既有 ALAC 24 位原生流程检查无损编码说明。完整构建结果另见最终验证记录。

编码依据采用项目方和平台官方资料：

- [Xiph FLAC 特性](https://www.xiph.org/flac/features.html)
- [Apple 音频编码与解码](https://developer.apple.com/documentation/AudioToolbox/encoding-and-decoding-audio)
- [Apple ALAC 说明](https://developer.apple.com/documentation/musickit/audiovariant)
- [Xiph FLAC 与有损编码说明](https://wiki.xiph.org/FLAC)

本轮不声称已增加第三方提供商本来没有的音质，不绕过会员授权，也不保证所有来源和实体设备的完整可用性。继续沿用原包名与签名，构建优先使用 GitHub Actions。
