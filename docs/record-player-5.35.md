# v5.35.0 唱片播放页

按用户参考图改造现有播放页：横屏左侧为真实歌曲封面的旋转唱片、唱臂、进度和播放控制，右侧为同一音频时钟驱动的滚动逐字歌词，下方为常用入口。竖屏按空间安排唱片、歌词和控制区，小窗口保留完整控制并提供原歌词页入口。打开、收起、切换背景不新建播放会话。

播放背景提供跟随歌曲封面、自定义图片、纯色三种模式，模糊和遮罩独立保存。系统图片选择器只读取用户选择的图片；限制输入 32 MB，采样到不超过 1600 像素，处理图片方向后原子写入应用私有文件。取消或无效图片保留原文件。自定义背景与歌曲身份独立，切歌与重开页面后保留。返回跟随封面后使用新歌曲的实际封面，无封面时使用本地渐变。

唱片转动仅在播放、页面可见且未开启减少动态效果时进行；暂停停转。封面与背景持有缩小后的独立位图，不回收调用方的封面。歌词复用原逐字渲染、每曲偏移和实际音频时钟，手势受会话身份保护，旧曲的异步歌词不会覆盖新曲。原歌词页保留动效设置、重新获取和导入入口。

沿用原包名与签名，版本代码 85。继续使用 GitHub Actions 进行完整 Android 原生测试、64 来源匿名检测、签名和从 v5.6.0 / v5.34.0 覆盖升级验证。最终结果以后续验证记录为准。本轮布局修改不宣称解决先前第三方来源的账号、地区、协议或服务端问题。

实际原生截图检查后，将顶部工具栏覆盖在背景上，快捷入口放到右侧底部，给矮屏唱片保留空间；测试要求横屏唱片视图高度至少为主体的一半，并验证所有主操作点按目标。
