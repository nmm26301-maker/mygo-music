# 5.27 交互细节与状态反馈

在 5.26 已验证代码上打磨现有流程，未增加音乐源协议或新的音效引擎。

## 改动

- 宽屏均衡器改为左侧开关、预设和状态，右侧五个频段，避免原竖向表单在横屏只露出预设。窄屏保留可滚动单列。音效开关保留当前自定义曲线，恢复原声仍会关闭并清零。
- 频段拖动时只更新对应数值，不重设全部滑块。原生应用与持久化合并为至多约每 35 毫秒一次；松手及关闭面板补交最后值，减少密集参数写入和通知刷新。预设和开关仍即时生效。
- 歌词页进度条触摸拖动只预览目标时间，松手提交一次跳转；取消手势或期间换歌丢弃旧请求。键盘等非触摸用户调整仍即时跳转。预览期间播放器继续播放，歌词保留真实进度，不伪造预览时的音频状态。
- 歌词页底部时间显示剩余定时，可点击打开定时设置；播放通知也显示并按秒更新倒计时。定时取消或结束后不显示过期标签。
- 长歌词状态说明单行省略，避免挤压顶部操作区。

Android SeekBar 官方回调依据：https://developer.android.com/reference/android/widget/SeekBar.OnSeekBarChangeListener 。实现使用原生触摸生命周期，区分用户操作与程序刷新。

## 验证状态

本地既有 22 项 Node 回归通过。新增原生实际多次移动只预览、松手一次跳转、取消与换歌丢弃、键盘跳转、时间标签及入口检查；均衡器宽屏五段可见、真实自定义拖动末值落盘、关闭再开启保留曲线且播放器不重启检查。云端完整 Android 回归、原签名和从 5.26.0 覆盖安装待完成后记录。未声称完全无缺陷或所有实体设备已验证；本轮没有对实际音源做新的音质测量。
