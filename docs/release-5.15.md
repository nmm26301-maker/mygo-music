# MyGo Music Android 5.15.0

本轮沿用现有项目完成修改，没有重新初始化。包名 com.mygo.music，版本号 65，沿用原发布签名。请直接覆盖安装，保留原来的账号、插件、设置和音乐库。

## 本轮补齐

| 功能 | 实现与验证范围 |
| --- | --- |
| 音量均衡 | 读取来源 gain/peak，保留原版 4 dB 前级增益和峰值限制。降低音量直接作用于原生播放器，增益使用当前音频会话的 LoudnessEnhancer。离线文件保留增益信息，可在播放音质菜单中的音量均衡关闭。 |
| ALAC 无损音频 | 四种安卓架构的独立解码组件，将 ALAC/M4A 解码为完整 FLAC，再由原有播放服务播放。测试验证 16 位、24 位和声道数、来源播放、离线元数据、暂停、拖动、继续。 |
| HLS 分段离线缓存 | 完整下载有限时长的音频分段并生成 FLAC 后才进入缓存。测试覆盖主清单、标准 AES-128、清单和分段及密钥请求头、跨来源凭据隔离、服务器关闭后的离线播放、清理时取消任务。不会把播放清单当作缓存歌曲。 |
| 设置保存 | 同一来源跨多个窗口和管理器依次执行保存及确认，失败回滚；未修改的旧窗口不覆盖较新的值。 |
| 远程电台续播 | 根据来源真实状态识别结束，接续下一批队列；手动暂停不会被误认为播放结束。 |

## 保留并回归检查

插件安装与更新、模块运行、网络权限、账号和 Cookie、来源主页、搜索与分页、歌单及收藏、歌词、后台播放、通知和媒体控制。

手机内完成二维码登录：在播放器的登录窗口点保存并打开扫码 App，在打开的对应 App 中进入扫一扫，从相册选择刚保存的二维码，确认后返回播放器等待登录结果。无需另一台电脑。二维码必须由该平台对应的扫码 App 识别；第三方是否开放相册识别由其自身决定。

六种歌词效果：逐字弹起、沉浸流动、双色卡拉OK、大字专注、经典滚动、霓虹流光。动效跟随真实播放位置，暂停冻结、拖动重算，支持双语、同步微调和背景设置。有逐字时间数据时按来源时间显示，没有时使用已标明的估算。

测试清单包含 64 个固定版本插件。安装、模块载入、搜索、取得音频地址、原生解码是不同阶段，报告分别记录。成功安装不等于所有账号、订阅和设备条件下都能播放。最终逐插件检查记录随 APK 内置，也可在 GitHub 构建产物查看。

需要真实登录、会员、用户私服、远程播放设备的来源，必须具备其相应条件。macOS AppleScript、Windows 程序和下载的桌面可执行文件不能直接当作安卓程序运行。要求 0.1.31 协议的插件仍会被明确拒绝，当前兼容协议为 0.1.24，不能仅修改版本号假装兼容。YouTube 等平台的反机器人要求也没有被绕过。

分段离线缓存不支持直播、DRM 或 EXT-X-DEFINE 清单变量，这些内容不会作为完整离线歌曲写入。单曲转换限制为 128 MiB，超时限制 180 秒。内部解码组件不提供任意桌面 FFmpeg 或 yt-dlp 命令兼容。
