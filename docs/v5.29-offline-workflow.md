# v5.29.0：离线缓存成为独立播放队列

版本号 5.29.0，版本代码 79，包名和签名沿用已交付版本。

## 修复的使用问题

此前从离线缓存点击歌曲，实际调用整个曲库的播放入口，并修改全局在线音质。下一首可能走出缓存列表；同一列表中不同请求音质的缓存，也可能找不到对应文件而转到联网解析。

现在从缓存页点歌会建立只包含该页缓存的队列。每个条目携带原始歌曲标识和缓存音质，同曲的两种缓存可以分别播放。切歌、实际播完自动切换、随机和单曲循环都复用原生播放服务，解析只查对应本地文件。文件被清理或失效时给出重新缓存的提示，不尝试联网。离线队列拒绝混入未缓存的在线歌曲。

音质设置在离线期间仅保存后续在线播放偏好，不重建当前播放器。音质页展示当前缓存档位。暂停、拖动进度及关闭后继续播放保持原有能力；空服务恢复会按上次歌曲与缓存档位重建当前缓存列表，保留已保存进度，不恢复其他未缓存曲目。

## 歌词

原有成功获取歌词的本地保存继续保留。离线播放优先使用已保存的原始歌词，包括来源提供的逐字时间和翻译；没有保存时明确提示联网获取一次或导入。离线刷新不会再次调用来源。在线播放刷新失败或返回空歌词时继续显示已保存版本，避免清空可用歌词。

## 验证范围

新增 Android 原生检查覆盖真实缓存页点击、下载服务关闭后的播放、同曲多音质队列、自动切歌、随机与循环、在线偏好不扰动当前播放器、原生进度、空服务恢复、来源调用计数、歌词时间轴和失败/空结果回退、缓存失效不联网。完整既有回归、签名与覆盖安装由 GitHub Actions 执行，结果在交付说明中记录。

这些修复不意味着所有第三方平台均可无限制使用。实际登录、会员曲目授权、地区限制、远程设备及来源接口由对应平台决定；音质档位不会把有损源伪装成无损。
