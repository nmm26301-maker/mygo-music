# v5.31.0 播放失败后的原队列重试

播放失败弹窗原先调用界面的通用播放入口，将累计音乐库重新组装为队列。用户从本地歌单或来源推荐列表开始播放时，重试和登录后重试可能因此丢失原先的列表范围与队列元数据。弹窗和异步登录回调也可能晚于用户切歌或开始新的播放会话。

本次将重试交给持有原队列的播放服务。服务校验失败会话的请求代次、错误编号、当前索引与歌曲地址，再在原队列中重新解析当前条目。保留原索引、条目元数据、播放位置及服务中的音量、随机与循环设置；离线条目的缓存限制继续由原解析流程执行。连续电台批次失败时继续原批次补充流程，不重建全音乐库队列。

界面还校验服务实例。旧弹窗、已消费的错误、切歌、相同歌曲的新会话和停止后的迟到登录回调不能重启旧播放。过期操作提示用户操作当前歌曲。

新增 Android 原生检查通过实际插件安装、失败弹窗按钮、受控登录返回与本机音频播放，确认播放时钟推进，而不只确认接口返回成功。覆盖选定列表、索引、元数据、起始位置、音量、音质、随机与循环保留，以及同曲新会话、迟到登录和停止后的旧重试拒绝。完整构建结果以最终验证记录为准。

本次未修改二维码、推荐封面、歌词动效、音效或签名。受控登录检查不代表已使用真实会员账号完成授权。RoamDial 上一轮选中电台未通过原生启动检查，本次源码核对显示它直接返回站点地址，尚未证明是播放器缺陷，因此不声称已修好该第三方电台。
