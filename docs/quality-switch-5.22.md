# 5.22 音质切换稳定性

沿用包名、正式签名、原生播放器和现有插件协议。先在独立且不启动的原生播放器中准备新档位，准备并对齐进度后再移交当前播放。不会以请求档位冒充音源实际音质。

来源授权、HTTP、音频准备或解码失败时，原播放器、播放进度和暂停状态继续保留，音质偏好恢复到当前实际档位，并显示原始来源错误和可用的登录或重试入口。准备过程中暂停、拖动、音量变化沿用当前服务状态。快速选择只采用最后一个请求；重新选择当前档位取消待处理请求；切歌和停止取消旧请求，避免旧回调重新启动歌曲。同曲已上报状态跨多次暂停切换保留，避免重复 played。

缓存对当前音频和待切换音频分别保留占用，交接或取消时释放。来源字段、账号、请求头与原有音量均衡仍沿用既有实现。解码临时文件随取消或交接转移所有权。

全屏歌词页顶部新增音质按钮，可以直接使用现有三档选择。原有十种动效保持不变。

Android 官方媒体状态与异步定位依据：https://developer.android.com/reference/android/media/MediaPlayer 。独立播放器不会启动第二路音频；实际采用后才启动。

新增原生回归覆盖授权拒绝、HTTP 403、解码器拒绝、准备时暂停和拖动、快速选择、取消、切歌和停止，并检查实际播放器身份、时钟、偏好和来源上报。已有 ALAC 16/24 位及全套歌词、缓存、后台、登录、插件回归继续运行。
