## 实现边界

主题只能切换布局与绘制、不能新建播放器或重建当前队列。谱线来自实测 PCM 或系统 Visualizer，波形明确区分单声道与真实左右声道。采集只作用本应用输出，不用麦克风，不保存原始音频。无音频数据时显示未授权/远程/静音状态而非循环假条。系统许可使用标准请求，不静默开启。

性能以按需释放、前台/暂停降频、纹理有界和 UI/采样线程分离保证实现层面约束；实体设备帧率/耗电未经测量不得写为已通过。主题预览必须来自同一实际 UI 的绘制，不能另画效果图假装真实页面。主题切换、队列编辑和校准沿用会话/手势失效保护。
