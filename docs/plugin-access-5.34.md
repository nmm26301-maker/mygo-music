# v5.34.0 插件授权与逐项可用性

用户截图中的提示对应已保存为关闭的网络权限。旧代码只在权限键不存在时询问授权；键已存在且为 false 时直接执行插件，最终由网络桥抛出普通错误。现把网络检查统一放到插件调用前，已关闭的权限也可在前台重新允许，允许后继续原操作。拒绝或取消不会运行插件代码或访问网络，也不会强迫立即再次授权。

同一界面多个管理器对同一插件的请求合并为一次授权，不同插件排队展示。插件停用、删除、权限声明变化或管理器关闭时，旧授权请求失效。后台不弹授权窗口、不静默开启权限，而是带来源身份返回前台恢复操作。网络授权与辅助程序、酷狗设备注册保持分开。

兼容根级 requestHeaders 与 permissions.requestHeaders 两种声明位置，沿用域名范围、资源种类、请求头名称校验和跨源重定向隔离。来源返回的 MP4、M4A、M4B 在原生准备超时或启动时钟停滞时，可以进入有输入、输出和时间限制的完整兼容解码；音源编码信息继续保留，兼容 FLAC 不冒充原始无损音频。

咪咕公开仓库已从 Maker-World/mygo-music-migu 改名为 Maker-World/MygoMusicMigu。本版更新市场与固定检测包至 0.2.2，固定提交 1e334b305822be59c359f7768d5e6a1cec88a735，归档 SHA-256 为 5f48cb57c4d5c9d554956c0f0c8287d578b2afdb558058c4903fc3fe359dcbe2。旧安装身份与配置继续复用，避免改名后生成重复插件。

## 验证方式

新增原生检查使用真实授权按钮及本地 HTTP 服务，验证保存为 false 后首次使用、跨管理器合并、不同来源排队、拒绝与后续恢复、后台错误可恢复、管理器关闭与权限变化的失效保护、源页面加载、嵌套媒体请求头和原生音频时钟。另一原生检查用真实 MP4 音频覆盖原生准备停滞后的完整解码、暂停、跳转、恢复、清理和过期超时回调。

全部固定来源的检测不再直接预写允许值：每个成功安装且声明网络的插件，均先设为 false，再通过真实前台授权按钮继续；随后分别检查搜索、播放地址和原生短时播放。报告保留样本曲目和返回格式，区分未配置、需登录、未导出接口、协议不支持、连接失败和播放未确认。

最终构建、逐来源结果与限制以后续验证记录为准。通过授权流程不等于每个平台所有歌曲均可播放。服务器型来源仍需要用户自己的服务器配置，平台会员与远程设备需要相应授权，0.1.31 协议等未移植能力不能通过虚改版本号伪装支持。
