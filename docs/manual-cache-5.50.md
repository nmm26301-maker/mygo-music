# 5.50 当前歌曲缓存

5.49.0 已支持离线播放、按音质删除和自动缓存。关闭自动缓存后，离线缓存页缺少手动保存入口。

| 路径 | 处理及验收 |
| --- | --- |
| 正在播放的插件歌曲 | 从离线缓存页保存当前音质。即时更新结果、容量和歌曲列表，并保持当前播放。 |
| 下载与授权 | 复用原完整文件验证和下载队列，携带当前来源请求头。检查原直链文件与点播 HLS 的编码数据。 |
| 离线 | 禁用来源并关闭测试服务后，从缓存列表启动原生播放。 |
| 其他功能 | 回归十种主题、逐字歌词、插件搜索、扫码登录、离线队列、缓存删除与覆盖安装。 |

手动保存适用于已准备好的在线插件直链和点播 HLS。直播、远程控制、本地文件和已转为临时文件的兼容解码结果不走这一入口。
