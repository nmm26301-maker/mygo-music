# 5.23 四种新歌词动效

在原有十种样式后追加流星拖尾、翻页入场、涟漪扩散、双行交接，编号 10 至 13，不覆盖已保存的旧样式。歌词页顶部动效菜单与外观选择器均可进入，总计十四种。

- 流星拖尾：光点与短尾迹沿当前演唱字符进度移动，不模拟真实音频节拍。
- 翻页入场：当前行以轻微纵向透视进入，随后保持清晰稳定。保留完整字形排版和译文。
- 涟漪扩散：演唱中的字周围出现两圈淡色扩散环，固定最多两圈，无随机粒子系统。
- 双行交接：显示当前行和下一行，在来源给出的下一行时间附近渐进交接。下一行仍是预览，不提前显示已演唱高亮。

四种效果只按歌曲及歌词时间取样，暂停冻结，后退重算。减少动态效果、强度为零或系统关闭动画时，停止附加装饰与位移，保留演唱进度。纯文本不生成演唱时间。混排和双向文字继续采用既有安全排版，逐字符装饰只对可安全拆分的左到右文字生效。

实现使用现有 Android Canvas，新增辅助类复用 Paint、Camera 和 Matrix，不引入另一套播放器或网页渲染器。翻页依据 Android 官方 Camera 与 Canvas 接口：https://developer.android.com/reference/android/graphics/Camera ，https://developer.android.com/reference/android/graphics/Canvas 。保留既有 AMLL 和 KaraokeText 授权与原文件；本轮新增绘制代码在现有应用中实现。

新增像素回归覆盖真实绘制、样式区别、暂停/后退一致、系统和应用减少动态效果、强度为零、纯文本、窄屏混排与真实菜单保存。原有音质、登录、扫码、缓存、后台及插件回归继续保留。完整云端结果、覆盖升级和交付校验待构建完成后记录。
