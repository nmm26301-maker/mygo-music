# 5.24 歌词动效质感与可读性

沿用十四种样式与已有编号，不改变用户已保存的选择。最近新增的双行交接、流星拖尾、翻页入场、涟漪扩散放到快捷菜单前四项，完整样式选择器保持原顺序。

## 画面优化

- 流星拖尾使用连续渐变尾迹、柔和光晕和稳定光点，去掉按字符反复变化的小散点。颜色变化时更新渐变，普通帧复用渐变与绘图对象。
- 涟漪采用短淡入、缓慢扩散和逐渐淡出，两圈光环都在结束前衰减，中心光晕放在字形下方。
- 翻页变形减轻，位移缩小，并按显示密度设置透视距离；当前行仍保留完整排版。
- 最近四种样式的离场行按边缘距离淡出，避免上下文在边界突然切断。透明层范围限制到可见区域；当前行和下一行的双行位置衔接检查继续保留。
- 封面背景复用目标矩形，减少逐帧临时对象。

所有附加动效继续按歌词/歌曲时间取样，暂停冻结、拖动重算。减少动态效果、零强度与系统关闭动画仍受支持。纯文本不生成时间；双向文字沿用安全排版。旧音质、登录、扫码与后台功能不更换实现。

Android 官方绘图依据：https://developer.android.com/reference/android/graphics/RadialGradient 、https://developer.android.com/reference/android/graphics/Canvas 、https://developer.android.com/reference/android/graphics/Camera 。新增柔光绘制使用现有原生渲染器，保留原有开源声明和文件。
