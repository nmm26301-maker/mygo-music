# 5.51 兼容音频手动缓存

5.50.0 可手动保存直链和点播 HLS，兼容解码完成后播放的临时音频缺少保存路径。

| 情况 | 处理及验证 |
| --- | --- |
| 兼容解码后的在线插件曲目 | 缓存已经生成的完整音频，保存播放所用的音质及来源编码。 |
| 保存后立刻切歌 | 保存任务持有独立读取句柄。原临时路径可在切歌时移除，写入的文件仍与该临时音频逐字节一致。 |
| 清空及即时重试 | 关闭旧读取句柄，提交新任务。旧任务不得在清空后发布文件。 |
| 音源停止及离线 | 禁用测试插件并关闭音源，通过离线缓存列表播放保存的音频。 |
| 回归 | 继续验证直链字节、HLS AAC 数据、歌曲队列、主题、歌词、登录和旧版覆盖安装。 |

缓存使用原有容量和文件验证机制。直播、远程设备播放、本地曲目不适用。
