# 5.26 音效与睡前体验

## 范围

保留来源的标准、高品质、无损优先请求与失败安全音质替换。新增本机播放会话均衡器，五个逻辑频点 60、230、910、3600、14000 Hz，各 ±6 dB；设备原生频段不同则在对数频率上插值并限制在设备范围。原声平直、人声清晰、温暖耐听、低频饱满、明亮通透和自定义，开关与曲线保存并实时应用，不改变歌曲进度或队列。

新安装和旧版升级默认关闭均衡器。频段提升时，按实际设置的最大正增益额外留 1 dB 余量，折算为播放器输入衰减，与既有音量、焦点压低和来源音量均衡合并。它是静态余量，不是已测量的真峰值限制器，也不声称恢复压缩音频丢失细节。均衡器绑定当前播放器音频会话，切歌/切音质时释放旧实例再绑定新实例，不接管系统总混音。设备不支持或控制权不可用时取消本应用的增益补偿，保持播放，显示状态；控制权变化触发状态刷新。

音质菜单新增音效与均衡器、定时暂停入口。歌词动效菜单也可开启定时暂停。15、30、60 分钟倒计时，或播完本曲后暂停。倒计时按单调时钟计时并在后台播放服务中执行，可跨切歌；本曲结束模式在自然结束时先于单曲循环/队列推进暂停，手动切到另一歌曲会取消。停止播放清除定时器。它不跨服务进程终止或重启保存，也不负责关闭外部其他应用。

## 验证状态

本地既有 22 项 Node 回归通过。新增 Android 测试包含真实均衡器启用/频段读回、余量合并、被更高优先级会话客户端夺取控制时的回退与恢复，真实预设 UI/保存/重开/恢复原声且不重启播放器；倒计时跨切歌、取消、真实播放时钟暂停、本曲结束先于循环、手动切歌与停止清除定时。既有真实 ALAC 16/24 位音质切换检查增加新会话均衡器生效断言。云端完整回归、签名与从 5.25.0 覆盖安装待完成后记录。实体手机、耳机听感和频率响应尚未测量。
